Papers 0.3.1

  • Pinch to zoom into an open document, up to 4× its fitted size. Zoom out again at fitted size to return to the grid.
  • Drag documents directly into Mail, Finder, and other apps that accept files, without an attachment picker.
  • Drag any selected document to copy the entire selection as separate files. A count badge identifies bulk drags, and duplicate filenames are kept distinct.
  • Improved quick-drag handling, file lifetime, and cancellation. Failed preparation never silently sends only part of a selection.

Files that are not cached download while preparing the drag. If you release before they are ready, Papers asks you to drag the selection again.
