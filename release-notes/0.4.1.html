Papers 0.4.1

  • Document deletion now responds immediately with a smooth, reversible animation while Paperless processes the request.
  • Successful deletions close the grid gap with the same fluid reflow used for zoom changes. Failed or cancelled deletions return to place without jumping.
  • Bulk deletions track moving documents by stable identity, keeping interrupted grid motion continuous.
  • Development, preview, and updater-validation builds can no longer publish or respond to production Spotlight document entries.
  • Papers Test includes an explicit maintenance command for removing entries created by older preview builds without touching documents or the production index.

Deletion animation respects macOS Reduce Motion. Spotlight indexing remains enabled for the signed production app.
