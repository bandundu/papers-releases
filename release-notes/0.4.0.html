Papers 0.4.0

  • Optional document information below grid thumbnails: titles, localized dates, and independently selectable document type, correspondent, and tag pills. Enable these in Settings → General.
  • Tag pills match Paperless-ngx colors. Long names truncate and additional tags use a compact +N count. Metadata remains available offline.
  • Smooth, interruptible animations when showing or hiding document information, with support for macOS Reduce Motion.
  • Scroll vertically and horizontally with a trackpad after pinching to zoom into a document.
  • Removed bottom notification and progress overlays. Transfer status and cancellation remain available in Transfers.
  • Cleaner application menus without unnecessary trailing ellipses.

Metadata refreshes on launch, every 10 minutes, and with ⌘R. Empty or unassigned values stay hidden.
