# Papers

A minimal, native Mac client for your Paperless-ngx library.

**[Download Papers for Mac](https://github.com/bandundu/papers-releases/releases/download/v0.1.0/Papers-0.1.0-arm64.dmg)** — version 0.1.0 · Apple Silicon · macOS 12 or later

- Browse document previews with smooth scrolling and open documents in a focused reader.
- Search titles and synced OCR text locally for quick results.
- Find documents in macOS Spotlight and open them directly in Papers.
- Feel at home with native Mac controls, sharing, and light or dark appearance.

## Get started

You need an existing **Paperless-ngx server and account**. Papers connects to your library; it does not include a server.

1. Download and open the DMG.
2. Drag **Papers** into **Applications**, then open it.
3. In Settings, enter your server address and API token (or username and password), test the connection, and apply.

The app is Developer ID signed and notarized by Apple. This build supports Apple Silicon Macs; Intel Macs are not supported.

This repository contains release downloads and this guide. Application source code is not included.
